<Notice kind="moves" title="从这一站开始机械臂会动">
清空两只臂周围半米内的东西，人站在侧面。<kbd>空格</kbd> 是急停：目标冻结在当前位置，舵机保持力矩不掉。

## 启动控制台

```bash
uv run soarm-console --mode idle
```

打开 [http://127.0.0.1:8000](http://127.0.0.1:8000)。连接时手臂会从当前位置上力矩并停在原地，不会跳。

你应该看到：两只臂都显示“已连接”，三路画面都有图像。某只臂没连上时，页面会写明原因。

## 确认左右没有接反

把手放到**左臂**的夹爪前面。“左”按机器人自己的朝向算，也就是你站在机械臂身后时的左手边。

<LeftRight />

手应该出现在“左臂腕部”的画面里。出现在右边的话，把 `config/config.yaml` 里两个腕部相机的 `device` 对调，重启控制台。

## 一次只动一只臂

第一次上电建议先只动一只：在另一只臂的面板上点“停用”，它在任何模式下都只保持当前位置。这只验证完再换另一只。

## 回初始位

按 <kbd>G</kbd>。手臂用两三秒展开到初始位：夹爪水平朝前，离基座约 26 cm。

<Poses />

你应该看到：腕部相机的画面是正的，画面下方能看到夹爪。

## 腕部跟随

按 <kbd>2</kbd>。把手伸到腕部相机前 30–40 cm，慢慢向各个方向移动。

<Follow />

| 应该看到 | 不对的话 |
|---|---|
| 手臂朝手的方向转 | 反而躲开：把该臂的 `follow_pan_sign` 或 `follow_tilt_sign` 改为 `-1` |
| 朝中间转到头时离相机立柱还有距离 | 收紧 `arms.<臂>.joint_limits.shoulder_pan` |
| 手拿开约 1.5 秒后回初始位 | 见[排障](../troubleshoot/) |

## 深度引导

按 <kbd>3</kbd>。把手伸到深度相机看得见、腕部相机看不见的位置，比如两只臂正前方半米、偏高一些。

<Guide />

你应该看到：离手近的那只臂转过去，把手带进它的腕部画面，然后一直跟着。

臂不动、或者转过去了但腕部画面里看不到手，说明外参对不上了，多半是两只臂和相机立柱的相对位置变过。先确认云台在工作刻度上，仍不行就去[外参标定](../calibration/)重新标一次。

## 收手

点页面上的“收到休息位并释放力矩”，或者回到终端按 <kbd>Ctrl</kbd>+<kbd>C</kbd>。两种方式都会先把手臂收到停放的姿态，再释放力矩，手臂不会摔下来。

<Notice kind="unverified">
键盘控制（按 <kbd>1</kbd>）的前后、左右、上下方向没有在真机上逐一确认过。要用的话，先轻点一下每个方向键，确认方向与界面标注一致。
</Notice>
