## 连接

| 现象 | 处理 |
|---|---|
| `scan` 没有舵机应答 | 检查 DC 电源和跳线帽位置（B 位）；换一根 USB 线 |
| 串口打不开，提示权限 | `sudo usermod -aG dialout $USER` 后注销重新登录 |
| 页面显示某关节“行程限位是出厂值” | 这只臂没有校准过，见[新套机上电](../new-kit/) |
| RealSense 打不开 | 确认接在 USB 3 口；序列号要填 `soarm-tools cameras` 输出的那个 |
| 腕部相机画面是另一路的 | 两个 `device` 填反了，或相机换过 USB 口，重新运行 `soarm-tools cameras` |
| 腕部相机画面是侧的 | 调整配置里的 `home.wrist_roll`（默认 −90） |

## 运动

| 现象 | 处理 |
|---|---|
| 提示“受到阻挡，已让位” | 有东西挡住了。排除遮挡后它会自己恢复 |
| 键盘控制提示“到达可达范围边界” | 目标超出了可达范围，往回移动即可 |
| 跟随时手臂躲着手 | 把该臂的 `follow_pan_sign` 或 `follow_tilt_sign` 改为 `-1` |
| 跟随发抖 | 调小 `follow.filter_min_cutoff`；掉头时冲过头就调小 `follow.max_lead_deg` |
| 跟随跟不上 | 先看页面上腕部相机的帧率是否约 30；再调小 `follow.smooth_time` |
| 想换回旧的跟随手感 | 配置里设 `follow.controller: legacy` |

## 深度引导

| 现象 | 处理 |
|---|---|
| 重新上电后相机垂着 | 正常。用 `soarm-tools head-set` 转回工作刻度，见[本机配置](../config/) |
| 深度引导完全不动 | 云台多半被碰歪了，先转回工作刻度；仍不行就[重新标定](../calibration/) |
| 臂转过去了但腕部画面里没有手 | 外参或安装偏角不准，[重新标定](../calibration/) |
| 远处路过的人也会引起反应 | 调小 `fused.depth_range` 的上限（一号套机用 1.3 米） |

## 现场

| 现象 | 处理 |
|---|---|
| 网页顶部有黄色提示条 | 有一只臂被借出去了：`scripts/lab.sh restore` |
| 急停后不动了 | 人到场确认安全，在网页上解除急停，再选模式 |
| 服务起不来 | `scripts/production.sh logs` 看原因；多半是串口或相机被别的程序占着 |
| 终端里 Ctrl+C 之后手臂没收 | 急停状态下退出会保持力矩不动，这是有意的。解除急停后再退出 |

## 已知的不足

- 手臂伸出时有约 2–3 cm 的重力下垂，逆解没有补偿。
- 外参是粗外参，只保证能把手带进腕部相机的视野。
- 右臂腕部相机的安装偏角样本不足，暂用左臂的估计值。

每一项的实测数据在仓库的 `docs/devices/VERIFIED.md` 里。
