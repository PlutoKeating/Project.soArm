## 核对电压

<Notice kind="caution" title="接错电压会烧舵机">
STS3215 舵机有 7.4 V 和 12 V 两种版本。一号套机的舵机都是 7.4 V 版（耐压上限 8 V）：实测机械臂那两路供电约 5 V，云台那一路约 7.7 V。**不要接 12 V 电源。** 拿到别的套机时，先看舵机标签。
</Notice>

## 接线

| 接什么 | 接到哪 | 要点 |
|---|---|---|
| 三块控制板的 USB | 电脑任意 USB 口 | 跳线帽在 **B 位**（USB ↔ SERVO） |
| 三块控制板的 DC 口 | 各自的舵机电源 | 只插 USB 时舵机不应答 |
| 两个腕部相机 | 电脑 USB 2 口 | 记住各自插在哪个口，之后别换 |
| 深度相机 | 电脑 **USB 3** 口 | 接在 USB 2 口上打不开深度流 |

<Wiring />

通电前把两只臂摆在自然收拢的位置。通电后舵机没有力矩，手臂保持无力状态，这是正常的。

## 确认舵机都有应答

```bash
uv run soarm-tools scan
```

它会列出每个串口上的舵机。你应该看到三个串口：

- 两个串口各有 **6 个舵机，ID 1–6**：这是两只机械臂。
- 一个串口有 **2 个舵机**：这是云台。一号套机上是 ID 7（左右）和 ID 8（俯仰）。

<ArmJoints />

把云台那个串口的路径记下来，下一站要用。

某个串口“没有舵机应答”时，依次检查：DC 电源是否接通、跳线帽是否在 B 位、换一根 USB 线。

## 确认相机都被识别

```bash
uv run soarm-tools cameras
```

应该列出两个 UVC 相机（各存了一张快照）和一台 RealSense。输出里那两条带 `usbv2` 的路径下一站要用。

<Notice kind="info" title="新套机在这里换乘">
如果你手上是一套全新的套机，下一站去[新套机上电](../new-kit/)。用一号套机的话继续往下走。
</Notice>
