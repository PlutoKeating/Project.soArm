<Notice kind="info" title="什么时候需要做">
新套机第一次用，或者两只臂和相机立柱的相对位置动过。只是换了电脑、套机没动，用档案里的外参即可。
</Notice>

## 把相机低头到标定刻度

展示时相机朝前看，这个角度下看不到手臂。标定时要让它低头，能看见手臂往前伸出：

```bash
uv run soarm-tools head-set --port <云台串口> \
    --pan-id 7 --tilt-id 8 --tilt 2087
```

2087 是一号套机的标定刻度，相机低头约 59°。

## 让每只臂自己标定

<Notice kind="moves">
这只臂会依次摆 16 个姿态，往前上方伸出并朝内转，每个姿态 3–5 秒。清空它前方的东西。
</Notice>

控制台没有在运行时，直接执行：

```bash
uv run soarm-tools body-calib right
uv run soarm-tools body-calib left
```

演示正在常驻运行时，先把这只臂借出来，做完再还回去：

```bash
scripts/lab.sh lend right
uv run soarm-tools body-calib right
scripts/lab.sh restore
```

它把深度相机看到的手臂点云对到运动学骨架上，求出相机的位置，再把骨架投影回深度图做反向验证。验证不通过就不保存。

## 检查结果

看两处：

- 终端输出的相机位置应该在两臂之间的上方。一号套机在右臂基座系下是前 0.18 m、左 0.17 m、上 0.42 m。
- 打开 `calibration/body_right/check_*.jpg`，黄色骨架应该压在手臂上，指尖偏差两三厘米以内。

## 抬回工作刻度并换算外参

```bash
uv run soarm-tools head-set --port <云台串口> \
    --pan-id 7 --tilt-id 8 --tilt 1705
uv run soarm-tools tilt-calib --pitch-down 25
```

`tilt-calib` 测量此刻地面的方向，与标定时的地面方向相比，得到相机转过的角度，把外参换算过来。它需要独占深度相机，执行时控制台不能在运行。`--pitch-down` 是此刻大致的低头角度，帮它在画面里认出地面。

之后云台不要再动。运行中控制台会持续核对地面方向，对不上就暂停深度引导。

<Notice kind="unverified">
`tilt-calib` 是展会收尾时补上的命令，只有单元测试。展会当天这一步是手工换算的。第一次用时先加 `--dry-run` 看输出：测得的低头角度应与预期接近，外参转过的角度应等于两个刻度之差除以 11.4。
</Notice>

## 估计腕部相机的安装偏角

腕部相机装在夹爪上方、斜着往下看，光轴比夹爪指向低十几到二十度。这个偏角要估出来，深度引导才能把相机而不是夹爪对准手。

不需要专门操作：进入深度引导模式（按 <kbd>3</kbd>）正常伸手互动，腕部相机和深度相机同时看到手时会自动积累样本，重启不丢。页面“外参标定”一栏显示每只臂的样本数。

每只臂攒够 20 对以上，点“用自动样本估计所选臂的安装偏角”。结果里的散布在 6° 以内可用。

| | 一号套机的结果 |
|---|---|
| 左臂 | 偏右 4.7°，偏下 14.9°（160 对一致的样本） |
| 右臂 | 样本不足，暂用偏右 3.5°、偏下 19.6° |

## 验证

回到[首次启动](../first-run/)的“深度引导”一步：把手伸到深度相机看得见、腕部相机看不见的位置，离得近的那只臂应该转过去并把手带进腕部画面。
