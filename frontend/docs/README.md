# 前端

单页控制台，三个文件，无构建步骤、无第三方依赖，由后端直接以静态文件提供。

| 文件 | 内容 |
|---|---|
| `index.html` | 页面骨架：顶栏与急停、模式与动作按钮、三栏面板、标定面板 |
| `style.css` | 样式。深色界面，颜色与圆角集中在 `:root` 变量里 |
| `app.js` | 全部逻辑：取元数据、建界面、WebSocket、按键、渲染状态 |

## 开发

启动后端后直接改文件、刷新浏览器即可：

```bash
uv run soarm-console --mock
```

语法检查：`node --check frontend/app.js`。

## 操作说明

- 空格：急停 / 解除急停。
- `0`–`3`：切换模式；`G`：回初始位。
- 键盘控制模式下，两臂的键位显示在各自面板底部，按住时对应键帽会高亮。
- 每只臂面板标题右侧的“停用 / 启用”按钮可以让该臂只保持当前位置。
- 关节条上蓝色是实测位置，黄色是已下发的目标。
- 深度引导模式下，被选中去跟随的那只臂的面板边框会高亮。

架构说明见 [ARCHITECTURE.md](ARCHITECTURE.md)。
